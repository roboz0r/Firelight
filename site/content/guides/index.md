- [Templates](/guides/templates/): plain HTML in F# interpolated strings, with bindings,
  conditionals, lists, directives and static values.
- [Lifecycle](/guides/lifecycle/): connecting, updating and cleaning up, and which lifecycle
  method to override for what.
- [Controllers](/guides/controllers/): state and lifecycle that any component can reuse.
- [Prerendering components at build time](/guides/prerendering/): Lit SSR at build time,
  declarative shadow DOM, hydration and prerender-safe components.
- [Component communication](/guides/communication/): properties down, events up, and context,
  signals or Elmish across.
- [Using web component libraries](/guides/component-libraries/): Web Awesome, Shoelace, Fluent UI
  or Carbon tags in F# templates.
- [Using JavaScript libraries](/guides/js-libraries/): npm libraries in components, with imports,
  bindings, loading on demand and lifecycle.
- [App architecture and loading](/guides/architecture/): structure a larger app, place its state,
  and load it fast without SSR.
